# Ducklang compatibility fixtures

The numbered fixtures are copied from the sibling `binned` repository's
MIT-licensed example suite. `closure_capture.duck` has the same source as
`binned/examples/functions/01_closure_capture.duck`; its shorter local name
keeps this directory organized by the behavior under test. `comptime.duck` is
specific to this compiler.

These programs form an executable compatibility slice, not a claim that the
complete Duck grammar is supported. The root README lists the admitted and
rejected grammar families.
